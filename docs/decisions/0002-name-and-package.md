# 0002. Name and package

- Status: accepted
- Date: 2026-11-15

## Context

The working title in the founding brief was "Priced In". The project needs a stable repository and import name before code is written.

## Decision

Project name **Priced In**; repository `priced-in`; Python package `pricedin`.

## Consequences

Imports read `import pricedin`. The distribution name on any package index is `pricedin`.
